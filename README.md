# MOORTTYS VOICE — Pack inicial de sonidos

Pack de inicio con nueve efectos originales sintetizados para este proyecto. Son sonidos genéricos originales; no son grabaciones de personajes, juegos ni marcas conocidas.

## Contenido

### 01_bienvenidas
- `01_bienvenida_chime`: bienvenida musical, cálida.
- `02_bienvenida_pop`: pop discreto para entradas rápidas.
- `03_bienvenida_ping`: ping digital corto.

### 02_suscriptores_y_vip
- `04_suscriptor_gold`: arpegio de celebración para suscriptor confirmado.
- `05_vip_sparkle`: brillo para eventos especiales o VIP.
- `09_momento_especial`: campanillas para donaciones u otros hitos.

### 03_efectos_live
- `06_whoosh_transicion`: barrido de transición.
- `07_level_up`: subida musical para metas/logros.
- `08_alerta_bajo`: golpe grave para una alerta destacada.

## Formatos
- WAV estéreo, 44,1 kHz, 16-bit: en las carpetas por categoría.
- MP3 192 kbps: en la carpeta `mp3`.
- `vista_previa.html`: puedes abrirlo en un navegador y escuchar los archivos MP3.
- `catalogo.csv`: índice de nombres, categorías y duraciones.

## Cómo usarlo en MOORTTYS VOICE
1. Descomprime este ZIP.
2. En la aplicación, abre la configuración de sonidos o subida de sonidos.
3. Sube un archivo WAV o MP3, según los formatos que acepte la versión desplegada.
4. Prueba el volumen en directo y baja el nivel si compite con la voz.
5. Asigna los sonidos suaves a entradas normales y los más brillantes a suscripciones/eventos especiales.
